CAD-Viewer Plus デモ

日本語化・フォント同梱版の動作確認ページです。すべてブラウザ内で動作し、図面がサーバーに送信されることはありません。

フル機能ビューア (cad-viewer)

フォント確認用サンプルを開く ＭＳ ゴシック / 明朝 / SHX / Arial / 宋体 / 맑은 고딕 の置き換えを確認 新規図面 日本語 UI、「モデル / レイアウト1 / レイアウト2」タブ ファイルを選んで開く 手元の DWG / DXF をドロップして確認 英語 UI で新規図面 言語切り替えとレイアウト名 (Layout1) の確認

その他のサンプルアプリ

シンプルビューア Vue なしの軽量 UI (左の一覧の fonts-sample.dxf で確認) 差分ビューア 2 つの図面の比較 (言語選択に「日本語」) サンプル DXF をダウンロード fonts-sample.dxf

確認ポイント

  • UI がすべて日本語で、中国語が残っていない (ブラウザが日本語なら自動で日本語)
  • UI の文字が Noto Sans JP で表示される (中国語字形にならない)
  • 図面の日本語が BIZ UD ゴシック / 明朝で表示される
  • %%c %%d %%p が ⌀ ° ± で表示される
  • Arial・中国語・韓国語の文字は Google Fonts から読み込まれる (ネットワーク環境による)
  • フォントとテンプレートは cad-data/ から読み込まれ、外部 CAD CDN へのアクセスがない
