# RemixCAD

[English](./README.md) | [日本語](./README.ja.md) | [简体中文](./README.zh-CN.md) | [한국어](./README.ko.md) | [Español](./README.es.md) | [Português](./README.pt.md) | [Русский](./README.ru.md) | [Čeština](./README.cs.md)

> **Это форк.** RemixCAD — форк проекта
> [mlightcad/cad-viewer](https://github.com/mlightcad/cad-viewer) (лицензия MIT).
> Он развивается независимо и **не связан с автором исходного проекта и не
> поддерживается им**. Сообщайте о проблемах этого форка в
> [issues этого репозитория](https://github.com/cool0707/remix-cad/issues),
> а не в исходный проект.

Просмотрщик и редактор DXF/DWG, полностью работающий в браузере: разбор
чертежей, обработка геометрии и отрисовка (Three.js / WebGL) выполняются на
клиенте, поэтому чертежи не покидают устройство пользователя.

## Что добавлено в этом форке

- **Японский интерфейс**: полная локаль `ja` для всех пакетов (просмотрщик,
  лента, командная строка, диалоги, плагины, сравнение чертежей, офлайн-экспорт
  в HTML). Язык определяется по настройкам браузера.
- **Шрифты размещаются в приложении, без CAD CDN**: шрифты и шаблоны чертежей
  отдаются самим приложением (`resources/cad-data` → `./cad-data/`).
  - Текст чертежей: включены **BIZ UD Gothic / Mincho**, они заменяют
    MS Gothic / MS Mincho и служат резервным шрифтом по умолчанию.
  - Другие письменности загружаются по требованию из **Google Fonts**
    (Arial → Arimo, SimSun → Noto Serif SC, Malgun Gothic → Noto Sans KR и т. д.).
  - Текст интерфейса: **Noto Sans JP** (размещается локально через
    `@fontsource-variable/noto-sans-jp`).
- **Локализованные имена страниц печати** в новых чертежах вместо китайских имён из шаблона.
- **Понятные термины для тех, кто не работает с CAD** — в интерфейсе используются обычные слова:
  блок → символ, атрибут блока → свойство символа, пространство модели → холст, лист → страница печати,
  штриховка → заливка узором, внешняя ссылка → связанный чертёж, быстрый выбор → выбор по условиям и т. д.
  Во всплывающих подсказках CAD-термин указан в скобках (во всех локалях).
- **Перемещаемая панель инструментов** — перетащите ручку (⠿), чтобы поставить панель в любое место;
  меню ⋯ рядом с ней переключает вертикальный/горизонтальный вид или возвращает панель на исходное место:
  к левому краю области чертежа, а если левый край закрывает плавающая панель (слои и т. п.) — к правому. Если её закрывает панель, она
  возвращается туда сама. Подменю открываются в сторону центра экрана, положение запоминается.
- **Переключение способа выбора** — кнопка в строке состояния переключает стиль CAD
  (каждый щелчок добавляет) и замену по щелчку (Shift + щелчок добавляет или убирает,
  щелчок по пустому месту снимает выбор). Пока по умолчанию остаётся стиль CAD.
- **Импорт JWW / JWC (Jw_cad)** — демо-приложение открывает файлы `.jww` и `.jwc` (старый формат) через
  `@mlightcad/cad-jww-converter` (MIT; парсер [ezjww](https://github.com/monozukuri-ai/ezjww),
  Rust → WebAssembly, в Web Worker). Координаты переводятся из миллиметров листа в реальные
  миллиметры по масштабу группы слоёв, а лист становится границами чертежа.
- **Импорт SXF** (японский стандарт обмена САПР-данными для госзаказов) — демо-приложение открывает
  `.sfc`, `.p21` и их ZIP-варианты `.sfz` / `.p2z` через `@mlightcad/cad-sxf-converter` (MIT, TypeScript,
  портирован из [ezsxf](https://github.com/monozukuri-ai/ezsxf)). Частичные чертежи показываются в реальном
  размере основного вида, лист становится границами чертежа.
- **Вертикальное письмо (縦書き)** — текст с вертикальным шрифтом Windows (`@ＭＳ ゴシック`,
  например 縦字 из Jw_cad) и TEXT со стилем, у которого установлен флаг AutoCAD «вертикальный»,
  пишутся сверху вниз на экране и при экспорте в SVG / PDF встроенными шрифтами BIZ UD
  (`@mlightcad/cad-vertical-text`).

## Демо

- Онлайн: <https://cool0707.github.io/remix-cad/>
- Локально:

  ```bash
  pnpm install
  pnpm demo:build   # сборка всех пакетов и создание demo-dist/
  pnpm demo         # http://localhost:4300/
  ```

## Начало работы

Требуются [Node.js](https://nodejs.org/) >= 24 и [pnpm](https://pnpm.io/) >= 10.

```bash
git clone https://github.com/cool0707/remix-cad.git
cd remix-cad
pnpm install
pnpm dev          # полнофункциональный просмотрщик
pnpm dev:simple   # простой просмотрщик
pnpm build
pnpm test
```

## Шрифты и ресурсы

Всё, что просмотрщик загружает во время работы, находится в `resources/cad-data/`
(см. [README](./resources/cad-data/README.md)). При встраивании пакетов передайте
`baseUrl` в `AcApDocManager`; резервные шрифты настраиваются опциями
`defaultFonts` / `symbolFonts`. Шрифты SHX не включены; текст с ними отображается
шрифтом BIZ UD Gothic.

## Поддержка DWG

DXF читается встроенным парсером с лицензией MIT. DWG поддерживается
опционально через `@mlightcad/libredwg-converter` на основе
[LibreDWG](https://github.com/LibreDWG/libredwg) с лицензией **GPL-3.0**;
перед распространением учтите требования GPL.

## Поддержка JWW / JWC

`@mlightcad/cad-jww-converter` читает чертежи Jw_cad (`.jww` / `.jwc`): разбирает файл с помощью ezjww (MIT)
в Web Worker, преобразует в DXF и загружает встроенным DXF-ридером. Зарегистрируйте его и
разместите `jww-parser-worker.js` и `jww-parser.wasm` (из `dist/` пакета) в одной папке:

```ts
import { registerJwwConverter } from '@mlightcad/cad-jww-converter'

registerJwwConverter('./assets/jww-parser-worker.js')
```

JWW хранит координаты в миллиметрах листа. По умолчанию всё масштабируется по масштабу основной
группы слоёв (с наибольшим числом объектов), поэтому чертёж выглядит как в Jw_cad, а основной
чертёж измеряется в реальных миллиметрах. `scaleMode: 'layer-group'` использует масштаб каждой
группы, `scaleMode: 'paper'` оставляет миллиметры листа. Старый формат JWC преобразуется так же (шрифтов в нём нет, текст выводится как ＭＳ ゴシック).
Изображения, размещённые через `^@BM`, показываются как растровые: встроенные в JWW выводятся сразу, а
ссылающиеся на внешние файлы отображаются как отсутствующие, и файл можно указать в просмотрщике.
Обрезка изображений пока не применяется.

## Поддержка SXF

`@mlightcad/cad-sxf-converter` читает чертежи SXF Ver.3.1: SFC (`.sfc`), P21 (`.p21`, AP202) и их ZIP-варианты
(`.sfz`, `.p2z`). Парсер написан на TypeScript (без WebAssembly), обработка элементов портирована из ezsxf
(MIT). Чертёж раскладывается на линии, кривые, текст, заливки и штриховки и загружается встроенным
DXF-ридером.

```ts
import { registerSxfConverter } from '@mlightcad/cad-sxf-converter'

registerSxfConverter()
```

Координаты SXF — миллиметры листа, частичные чертежи размещаются с масштабом. По умолчанию всё
масштабируется по основному частичному чертежу: лист выглядит как при печати, а основной вид измеряется в
реальных миллиметрах; `scaleMode: 'paper'` оставляет миллиметры листа. Окружности, дуги и эллипсы остаются
кривыми, текст подгоняется под рамку SXF. Растровые изображения (атрибуты изображения SXF 3.1) показываются, если файл изображения вложен в
`.sfz` / `.p2z`; монохромный TIFF (G4) преобразуется для браузера, JPEG используется как есть. Отдельный
`.sfc` / `.p21` показывает рамку изображения как отсутствующее изображение. Файлы атрибутов (SAF) не загружаются.
