フル機能ビューア (cad-viewer)

フォント確認用サンプルを開く ＭＳ ゴシック / 明朝 / SHX / Arial / 宋体 / 맑은 고딕 の置き換えを確認 Shift_JIS の DXF を開く 文字コード宣言が ANSI_1252 の Shift_JIS DXF が文字化けしないことを確認 図面範囲で開く 初期表示「図面範囲」: 範囲外の円を無視して A1 枠 (LIMITS) を表示 同じ図面をオブジェクト範囲で開く 比較用: 範囲外の円まで含めて全体を表示 Jw_cad (JWW) の図面を開く A3・1/100 の平面図: 実寸で計測、画層「0-1 平面図 - 壁」、線種・ペン色・ブロック・文字 SXF (SFC) の図面を開く A3・1/100 の部分図と図枠: 実寸で計測、画層・線種・寸法・塗り・ハッチング SXF (P21) の図面を開く 同じ図面の P21 (AP202) 版。ZIP 版の .sfz / .p2z も開けます 新規図面 日本語 UI、「モデル / レイアウト1 / レイアウト2」タブ ファイルを選んで開く 手元の DWG / DXF / JWW / JWC / SXF (SFC・P21・SFZ・P2Z) をドロップして確認 英語 UI で新規図面 言語切り替えとレイアウト名 (Layout1) の確認

確認ポイント

  • UI がすべて日本語で、中国語が残っていない (ブラウザが日本語なら自動で日本語)
  • UI の文字が Noto Sans JP で表示される (中国語字形にならない)
  • 図面の日本語が BIZ UD ゴシック / 明朝で表示される
  • Shift_JIS の DXF (文字コード宣言なし・ANSI_1252・R2007 以降でも) が文字化けしない
  • ファイルを開く画面の初期表示に「図面範囲」があり、モデルは LIMITS、レイアウトは用紙枠で表示される (URL では ?view=limits)
  • JWW / JWC (Jw_cad) を開ける。図寸は主レイヤグループの縮尺で実寸に変換され (1/100 なら用紙 1 mm = 100 mm)、用紙が図面範囲になる
  • SXF (SFC / P21 / SFZ / P2Z) を開ける。部分図は主となる部分図の縮尺で実寸になり (1/100 なら用紙 1 mm = 100 mm)、用紙が図面範囲になる
  • %%c %%d %%p が ⌀ ° ± で表示される
  • Arial・中国語・韓国語の文字は Google Fonts から読み込まれる (ネットワーク環境による)
  • フォントとテンプレートは cad-data/ から読み込まれ、外部 CAD CDN へのアクセスがない
